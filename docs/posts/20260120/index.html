紹介記事#

1. 【備忘録】Windows11 + WSL2 + Docker の構築#

  • Q1: Dockerとはなんぞや？
    • A: Linuxのうえで動かすことを前提としている.
    • A: Linuxカーネルの上で動かす,より機能の制限されたコンテナを用意する. このコンテナを定義するのがDocker Image
    • A: MacのDocker Desktopは別物. つかいずらい.Linuxカーネルの代替物がDocker Desktop
      • MacのHomebrewでDocker CLIを入れる.
  • Q2: WSLは何している？
    • A: WindowsのうえでLinuxのコマンド（OS)を動かせるようにしている
  • Q3: Windowsとコンテナの関係は、仮想環境 (linux) 上の仮想環境 (コンテナ) のようなイメージ？
    • dockerはlinux上で動く仮想環境をコンテナという形で (他にはVMなどがあるけど) bulidする
    • WSLはWindows上でlinuxの仮想環境
  • Q4: dockerとdocker-composeの違いは？
    • A: dockerが基本で, docker-composeは参照先のファイル(docker-compose.yml)が変わっていろいろと設定.
  • Q5: dockerを使うことのメリットは？
    • 共同開発しやすい
    • 可用性
    • トレーサビリティ
    • ネットワーク層まで含む、など
  • Q6: 逆にコンテナ以外の仮想環境(VMなど)を使う用途はどんなものがあるでしょうか？
    • A: VMでは,仮想環境ごとにOSを変えて組み込める. もし, 仮想環境にOSまで組み込みたいならVM.永続的に使いたくないもの. 一方で、最近はコンテナ管理ソフトウェア（Docker）が優秀でコンテナが多く使われている。

2. 天体モデリング - 小惑星イトカワを可視化する#

  • Q1: 点群データには色がついていないと思うが, どこに色情報が入っているのか？
    • A:色の情報を入っていない. 拡張子には入っていない.法線ベクトルが効いているのかも？
  • Q2: .stlファイルの特徴は？
    • A: Lidarからの出力をそのまま転記したもの（らしい）
    • 3D／点群データの拡張子の一覧まとめ
