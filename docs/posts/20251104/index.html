紹介記事#

1. 深層学習時のデータ構造変化をトポロジーの側面から考える#

  • Q1: kベッチ数でいう, 「0次元の基本サイクルとは」なんですか
    • ０次元は「点」、１次元は「円」、２次元は「球」
  • Q2: ベッチ数が小さくなるということは、どのような意味合い？（わかりやすく分類できているということ？）
    • ベッチ数は、データ構造の複雑性にかかっている. カッコ()の中の数字が小さいほど、データ構造がシンプルになっている.
    • ベッチ数はあくまでも構造体の話で、それをデータ構造の複雑性
  • Q3: ベッチ数という指標をもちいて, 機械学習（NN)の処理過程を可視化することで、どのようなインサイトを得られる？
    • 「ReLUのほうがArctanhを使った方がよい」といういままでのノウハウ的な、経験値的な状態から、ベッチ数を用いて定量的に「活性化関数の良さ」を評価できるようになる
  • Q4: この論文の知見を使えば, よい機械学習（NN)の設計が見出せる？
    • Q3に同じく,
  • Q5: k次元のベッチ数はk次元のベクトルの抽象概念？k=1のC_1, C_2 は（カーネルの）座標軸の抽象概念？
    • イメージとしては正しい．座標を表現する軸の抽象化の集合
  • Q6: 「浅い層ではトポロジーの位相が同型になるように写像し、深い層では位相変化の起こるような写像を行う」というのは非線形関数の線形近似の抽象概念？
    • 直感的にはあってそう
  • Q7: この話とカーネルトリックの関係は？
    • ReLUは写像として非対称？
  • Q8 (議論) : 距離や、「近い」の概念は位相空間では定義が難しく、学習で暗示的に決めている。

2. discord ボイスチャットで遊んでみた#

  • Q1: Discordからの処理フローを考えたく, DiscordからVoiceConnectionのデータを取り出す？

    • VoiceConnectionでコネクションを確立しつつ、送信内容は「OpusSend」や「OpusRecv」を再生成・書き直している.

  • Q2: Opus形式にするのは必要な操作？圧縮はどうしても必要なのか？

    • どうしても必要な操作ではないが、エンコードやデコードの確認のため。

  • Q3: WhisperとRTCの関係は？RTC→Whisperで日本語等に解釈？（再確認）

    • Opus形式のアウトプットを、波形情報に変換(decode)して、whisperで文字認識させる流れ。
